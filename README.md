# Лабораторная работа №3 — Автосервис

## Описание проекта
Данное учебное приложение представляет собой двухсервисную систему для управления заявками в автосервисе. Проект разделен на Backend (обработка данных и API) и Frontend (пользовательский интерфейс).

### Основной функционал:
- Просмотр списка активных заявок на ремонт.
- Добавление новых автомобилей в очередь (модель, описание поломки, стоимость).
- Удаление выполненных или отмененных заявок.
- Валидация данных на стороне сервера.

## Стек технологий
- **Backend:** FastAPI, Pydantic, SQLite (sqlite3).
- **Frontend:** Flask, Jinja2, HTML5, CSS3.
- **Взаимодействие:** Синхронные HTTP-запросы через библиотеку `requests`.
